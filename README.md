# Java Interview Sandbox

A collection of runnable Java examples built while preparing for senior and principal software engineering interviews.

## Topics

- Collections
- Streams
- Functional Programming
- Generics
- Exceptions
- Concurrency
- Multithreading
- JVM Internals
- Memory Management
- Design Patterns
- SOLID Principles
- Algorithms
- System Design
- Records
- Sealed Classes
- Virtual Threads

## Technologies

- Java 21
- Gradle
- IntelliJ IDEA

## Purpose

Each class focuses on one interview topic and includes:

- Explanation
- Runnable code
- Common interview questions
- Best practices
- Time complexity (where applicable)
- Real-world enterprise use cases
